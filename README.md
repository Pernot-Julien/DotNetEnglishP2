# P2FixAnAppDotNetCode

## Présentation

Projet n°2 intitulé "Déboguez une application .NET" réalisé dans le cadre de la formation Développeur d'application .NET.

L'objectif du projet est de corriger les problèmes présents dans une application existante et de rendre son fonctionnement conforme aux attentes du projet.

## Installation

Cloner le dépôt GitHub :

```bash
git clone https://github.com/Pernot-Julien/DotNetEnglishP2.git
```

La version présentée pour l'évaluation se trouve sur la branche `dev`.

```bash
git checkout dev
```

Ouvrir ensuite la solution `P2FixAnAppDotNetCode.sln` avec Visual Studio.

## Exécution

Lancer l'application depuis Visual Studio.
